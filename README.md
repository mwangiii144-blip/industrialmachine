# Kenya Sewing Hub

Overview

Create a modern, elegant, responsive, and professional business website for a company that sells, repairs, and services sewing machines in Kenya.

The website should feel premium, trustworthy, and easy to navigate. Use smooth animations, clean typography, attractive product cards, and a professional e-commerce style layout.

The design should work perfectly on desktop, tablet, and mobile devices.
